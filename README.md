# Домашнє завдання №2: Основні структури даних

## 📂 Структура завдання

Завдання розділені на три частини:

---

### ✅ Завдання 1: Імітація обробки заявок (Queue)

Мета: Імітувати систему прийому та обробки заявок у сервісному центрі.

- Використано модуль `queue.Queue`
- Заявки автоматично генеруються та додаються до черги
- Потім заявки послідовно обробляються з видаленням із черги

**Файл:** `task_1_requests.py`

---

### ✅ Завдання 2: Перевірка паліндрома (Deque)

Мета: Перевірити, чи є введений рядок паліндромом.

- Використано `collections.deque`
- Програма враховує:
  - регістр (нечутлива до нього)
  - пропуски та неалфавітні символи
  - рядки з парною/непарною кількістю символів

**Файл:** `task_2_palindrome.py`
